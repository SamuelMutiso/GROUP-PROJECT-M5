# GearShift

GearShift is a peer-to-peer car rental marketplace. This repository contains the frontend of the application, built with React, Vite and Tailwind CSS.

## Requirements

- Node.js 18 or later
- npm

## Running the frontend

1. Clone the repository and open the folder in your terminal.
2. Install dependencies:

   ```
   npm install
   ```

3. Start the development server:

   ```
   npm run dev
   ```

4. Open the URL printed in the terminal (usually `http://localhost:5173`).

## Note

This repository contains the frontend only. There is no backend server connected, so pages that depend on live data (browsing cars, logging in, submitting bookings) will load and render correctly, but will not return real data.
